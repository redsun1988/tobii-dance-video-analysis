# Система сбора статистики просмотра танцевальных видео

Приложение для Windows, которое проигрывает танцевальное видео тестируемому зрителю,
в реальном времени отслеживает, куда падает его взгляд (айтрекер Tobii 4C или
имитация курсором мыши), кто из танцоров в кадре и в какую часть тела он смотрит,
а также — через веб-камеру — какие эмоции при этом испытывает сам зритель.
По окончании просмотра строится подробная статистика и сохраняется в CSV, Excel
и локальную базу данных SQLite.

## Возможности

- **Проигрывание видео** — один файл, несколько файлов или вся папка подряд, через
  системный видеоплеер по умолчанию (`start_menu.py`, `video_window.py`).
- **Трекинг взгляда** — координаты взгляда через Tobii 4C, либо (для тестирования без
  оборудования) имитация курсором мыши (`eye_gaze_tracker.py`).
- **Трекинг поз танцоров** — YOLO-Pose (Ultralytics) находит и трекает всех людей в
  кадре по частям тела: голова, торс, плечи, локти, кисти, бёдра, колени, стопы
  (`pose_estimator.py`).
- **Анализ взгляда** — сопоставление взгляда с позами танцоров, детекция саккад и
  подтверждённых фиксаций, накопление длительности по персонам/частям тела/переходам
  между целями взгляда (`gaze_analyzer.py`).
- **VLM-проба внимания** — при новой фиксации локальная vision-модель (через Ollama)
  кратко описывает, что могло привлечь взгляд в этой области кадра
  (`vlm_attention_probe.py`).
- **Сверка личностей** — если трекер разбивает одного танцора на несколько ID
  (перекрытие, выход из кадра), локальная VLM сравнивает фрагменты и объединяет их
  постфактум (`identity_reconciler.py`).
- **Демография танцоров** — оценка возрастной категории, пола, телосложения и
  доминирующего цвета одежды каждого танцора через локальную VLM
  (`demographics_estimator.py`).
- **Трекинг эмоций зрителя через веб-камеру** — во время просмотра видео камера
  снимает лицо тестируемого, и готовый (не VLM) классификатор эмоций лица DeepFace
  определяет эмоцию (angry/disgust/fear/happy/sad/surprise/neutral) с частотой раз в
  `EMOTION_SAMPLE_INTERVAL_S` секунд. Эмоции пишутся во времени на той же временной
  оси, что и события взгляда, что позволяет впоследствии сопоставлять "что было на
  экране / куда смотрел зритель" с тем, как менялось выражение его лица
  (`emotion_tracker.py`, `webcam.py`).
- **Предпросмотр и настройка веб-камеры** — из меню «Настройки» можно открыть окно
  с живым видео с выбранной камеры и, прямо из этого окна, вызвать нативный диалог
  настроек драйвера камеры (баланс белого, яркость, контраст, экспозиция, фокус и
  т.п. — набор зависит от конкретного устройства) (`webcam.py`).
- **Кеширование анализа видео** — поза/трекинг и демография каждого видео считаются
  один раз и переиспользуются для всех последующих сеансов с этим же файлом
  (`database.py`, `video_precomputer.py`).
- **Экспорт результатов** — подробные CSV-файлы и единый Excel-файл со всеми листами
  статистики за сеанс, плюс сохранение сводки и всех разрезов в SQLite
  (`gaze_analyzer.py`, `database.py`).
- **Консольный интерфейс** — управление стрелками/Enter/Esc, без ввода команд
  (`tui.py`, `start_menu.py`).

## Требования

- Windows (используются `pywin32`, DPI awareness, захват экрана через `PIL.ImageGrab`).
- Python 3.10+.
- Веб-камера — для трекинга эмоций (можно отключить в настройках, если камеры нет).
- Айтрекер Tobii 4C и пакет `CustomTobii4cTracker` — опционально; без них работает
  только режим имитации взгляда мышью (`AppConfig.GAZE_SIMULATION_ENABLED`).
- Локальный сервер Ollama с vision-моделью — опционально, нужен для VLM-пробы
  внимания, сверки личностей и демографии. Адрес задаётся в `config.py`
  (`AppConfig.VLM_BASE_URL`). Без него эти три модуля молча отключаются.
- Интернет при первом запуске трекинга эмоций — библиотека DeepFace скачивает веса
  модели распознавания эмоций (несколько МБ) один раз и кеширует их в
  `~/.deepface/weights`; дальше работает офлайн.

## Установка

```powershell
pip install -r requirements.txt
```

`requirements.txt` содержит все обязательные зависимости. Строка
`-e ../CustomTobii4cTracker` ожидает пакет драйвера Tobii 4C рядом с этим проектом —
если его нет, удалите или закомментируйте эту строку и оставьте
`GAZE_SIMULATION_ENABLED = True` в `config.py`, чтобы взгляд имитировался мышью.

Модель позы `yolo26n-pose.pt` уже лежит в репозитории и подхватывается автоматически.

## Запуск

```powershell
python main.py
```

Откроется стартовое меню (стрелки — выбор, Enter — подтвердить, Esc — назад):

1. **Данные о зрителе** — анкета тестируемого (ФИО, пол, возраст, род занятий, опыт в
   танцах), либо выбор уже сохранённого в базе профиля.
2. **Выбрать видео и запустить анализ** — один файл / несколько файлов / вся папка.
   Перед стартом, если трекинг эмоций включён, но камера ещё не выбрана, приложение
   предложит выбрать её сразу.
3. **Предпросчёт кеша видео** — headless-прогон видео на повышенной точности
   (без живого зрителя и веб-камеры) для заблаговременного расчёта позы/демографии.
4. **Настройки** — вкл/выкл: имитация взгляда мышью, VLM-проба внимания, сверка
   личностей, оценка демографии, трекинг эмоций через веб-камеру, игнорирование кеша
   БД; отдельными пунктами — выбор конкретной веб-камеры из числа найденных в системе
   и окно предпросмотра выбранной камеры (клавиша `S` в этом окне открывает нативный
   диалог настроек драйвера камеры — баланс белого, яркость и т.п.).

## Результаты сеанса

После каждого просмотренного видео в `output/<ГГГГММДД_ЧЧММСС>/` сохраняются:

- `gaze_events.csv` — все проанализированные кадры взгляда;
- `person_duration.csv`, `body_part_duration.csv`, `gaze_transitions.csv` — сводки по
  взгляду;
- `emotion_timeline.csv` — покадровая эмоция зрителя (доминирующая эмоция + баллы по
  всем 7 категориям на каждый опрос камеры) с привязкой ко времени сеанса;
- `emotion_duration.csv` — суммарная длительность/доля каждой эмоции за сеанс;
- `vlm_queries.csv`, `identity_reconciliation.csv`, `person_demographics.csv`,
  `demographics_queries.csv` — при включённых соответствующих модулях;
- `viewer_profile.csv`, `summary.csv`;
- `gaze_statistics.xlsx` — то же самое одним файлом, отдельными листами (включая
  «Emotion Timeline» и «Emotion Duration»).

Кроме файлов, сводка сеанса (включая доминирующую эмоцию и долю кадров с найденным
лицом) и разрезы по персонам/частям тела/эмоциям пишутся в SQLite-базу
`data/app_data.sqlite3` — это позволяет впоследствии анализировать статистику по всем
зрителям и видео сразу, не только по файлам одного сеанса.

В базу пишется и полная временная шкала эмоций (не только агрегат по сеансу) —
таблица `session_emotion_samples`: каждая запись привязана и к сеансу (`session_id`),
и к конкретному видео (`video_id`), а `video_time_s` — это позиция в самом видео (та
же временная ось, что и у `video_pose_cache`). По `video_id` + `video_time_s` можно
восстановить именно тот кадр видео, который зритель смотрел в момент этой эмоции —
`video_geometry.read_frame_at(file_path, video_time_s)` открывает файл видео (путь
берётся из таблицы `videos`) и возвращает нужный кадр. Выборка сохранённых сэмплов —
`Database.load_emotion_samples(video_id=..., session_id=...)`.

## Ключевые настройки (`config.py`)

- `GAZE_SIMULATION_ENABLED` — имитация взгляда мышью без Tobii 4C.
- `VLM_ENABLED`, `VLM_BASE_URL`, `VLM_MODEL_NAME` — проба внимания через локальную VLM.
- `IDENTITY_RECONCILE_ENABLED`, `DEMOGRAPHICS_ENABLED` — постфактумные VLM-модули.
- `EMOTION_TRACKING_ENABLED` — вкл/выкл трекинг эмоций через веб-камеру.
- `WEBCAM_INDEX` — индекс выбранной камеры (устанавливается из меню «Настройки»,
  `None` пока камера не выбрана).
- `EMOTION_SAMPLE_INTERVAL_S` — пауза между опросами камеры (по умолчанию 0.5 с).
- `EMOTION_DETECTOR_BACKEND` — бэкенд детектора лица DeepFace (`opencv` по умолчанию —
  не требует скачивания дополнительных весов).
- `FORCE_RECOMPUTE_VIDEO_ANALYSIS` — игнорировать кеш и пересчитать анализ видео заново.

## Примечания

- Все VLM-зависимые модули (проба внимания, сверка личностей, демография) и трекинг
  эмоций — необязательные надстройки: при недоступности Ollama/DeepFace/веб-камеры
  приложение печатает предупреждение и продолжает работу без соответствующих данных,
  не прерывая сеанс. Исключение — сам трекинг взгляда: без Tobii 4C и при выключенной
  имитации мышью сеанс не запустится вовсе, поскольку взгляд — основной результат,
  который не должен подменяться молча.
- `data/` и `output/` игнорируются в git — это runtime-данные конкретной машины.
